# BL Rundown Studio - Installation als App

## 🌐 App-URL

**[https://andynde.github.io/BL-Rundown/](https://andynde.github.io/BL-Rundown/)**

Öffne diese URL in deinem Browser, um die App zu nutzen oder zu installieren.

## 📱 Installation auf Android

### Chrome Browser
1. **Öffne die App** in Chrome: `https://deine-domain.de/index.html`
2. **Tippe auf das Menü** (⋮ oben rechts)
3. **Wähle "Zum Startbildschirm hinzufügen"** oder "App installieren"
4. **Bestätige** mit "Installieren"
5. Die App erscheint nun auf deinem Startbildschirm

### Samsung Internet
1. **Öffne die App** in Samsung Internet
2. **Tippe auf das Menü** (≡ unten rechts)
3. **Wähle "Seite hinzufügen zu"** → "Startbildschirm"
4. **Bestätige** die Installation

### Firefox
1. **Öffne die App** in Firefox
2. **Tippe auf das Menü** (⋮ oben rechts)
3. **Wähle "Zum Startbildschirm hinzufügen"**
4. **Bestätige** mit "Hinzufügen"

## 🍎 Installation auf iOS/iPadOS

### Safari
1. **Öffne die App** in Safari
2. **Tippe auf das Teilen-Symbol** (□↑ unten in der Mitte)
3. **Scrolle nach unten** und wähle "Zum Home-Bildschirm"
4. **Gib einen Namen ein** (z.B. "BL Rundown")
5. **Tippe auf "Hinzufügen"**
6. Die App erscheint nun auf deinem Home-Bildschirm

**Hinweis:** Auf iOS funktioniert die Installation nur mit Safari, nicht mit Chrome oder anderen Browsern.

## 💻 Installation auf Desktop

### Chrome/Edge
1. **Öffne die App** im Browser
2. **Klicke auf das Install-Symbol** (⊕) in der Adressleiste
   - Oder: Menü (⋮) → "BL Rundown Studio installieren"
3. **Bestätige** mit "Installieren"
4. Die App öffnet sich in einem eigenen Fenster

### Firefox
1. **Öffne die App** im Browser
2. **Klicke auf das Menü** (≡)
3. **Wähle "Diese Seite installieren"**
4. **Bestätige** die Installation

## ✨ Vorteile der Installation

### Als installierte App:
- ✅ **Offline-Funktionalität** - Arbeite auch ohne Internet
- ✅ **Schnellerer Start** - Direkter Zugriff vom Startbildschirm
- ✅ **Vollbild-Modus** - Mehr Platz für deinen Rundown
- ✅ **Native App-Erfahrung** - Fühlt sich an wie eine echte App
- ✅ **Automatische Updates** - Immer die neueste Version
- ✅ **Daten bleiben lokal** - Alle Rundowns auf deinem Gerät

## 🔧 Systemanforderungen

### Minimum:
- **Android:** Version 5.0+ mit Chrome 80+
- **iOS:** Version 11.3+ mit Safari
- **Desktop:** Chrome 80+, Edge 80+, Firefox 90+

### Empfohlen:
- **Android:** Version 10+ mit Chrome 100+
- **iOS:** Version 14+ mit Safari
- **Desktop:** Aktuelle Browser-Version

## 📊 Speicherplatz

- **App-Größe:** ~2 MB
- **Offline-Cache:** ~5 MB
- **Daten:** Abhängig von deinen Rundowns (typisch < 1 MB)

## 🔄 Updates

Die App aktualisiert sich automatisch, wenn du online bist:
1. Öffne die App
2. Wenn ein Update verfügbar ist, wird es im Hintergrund geladen
3. Beim nächsten Start hast du die neue Version

## ❓ Problembehebung

### App lässt sich nicht installieren
- **Lösung:** Stelle sicher, dass du die neueste Browser-Version hast
- **Alternative:** Nutze die Web-Version im Browser

### App funktioniert offline nicht
- **Lösung:** Öffne die App einmal online, damit alle Daten gecacht werden
- **Prüfe:** Ob genug Speicherplatz verfügbar ist

### App zeigt alte Version
- **Lösung:** 
  1. Schließe die App komplett
  2. Öffne sie erneut
  3. Oder: Deinstalliere und installiere neu

### Daten gehen verloren
- **Wichtig:** Daten werden lokal im Browser gespeichert
- **Backup:** Exportiere regelmäßig deine Rundowns (Feature kommt bald)
- **Vorsicht:** Beim Löschen der Browser-Daten gehen auch App-Daten verloren

## 🗑️ Deinstallation

### Android
1. **Halte das App-Icon** gedrückt
2. **Wähle "Deinstallieren"** oder ziehe es auf "Entfernen"

### iOS
1. **Halte das App-Icon** gedrückt
2. **Wähle "App entfernen"** → "Vom Home-Bildschirm entfernen"

### Desktop
1. **Öffne die App**
2. **Klicke auf das Menü** (⋮)
3. **Wähle "BL Rundown Studio deinstallieren"**
